# Quiz Game

This is a 20 question music guiz that I am building as part of AI agent building course

## Requirements

- Tested with Python 3.14
- No third-party packages (standard library only)

## How to run

- python3 play.py is all you should need to do


## How to play

- straightforward - enter 3 initials and off you go
- scoring - percentage of right/total plus speed bonus

## Project structure

- `play.py` — the game
- `quiz.py` — reads questions from quiz.json
- `scores.py` — saves and retrieves scores from scores.json


## High scores

- scores.json isn't committed to will need to be created in the 1st run - 1st time you run it you will get notified but just run a second time
